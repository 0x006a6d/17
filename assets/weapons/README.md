# 武器モデル（手に持たせる小物）

Mixamo のアニメーション（Without Skin）には武器メッシュが含まれないため、手のボーンに
BoneAttachment3D で武器モデルを付ける。実装では銃と日本刀を使用する。

| ファイル | 用途 | 出典/ライセンス |
| --- | --- | --- |
| `pistol.glb` | 銃（9mmオート相当。実名は出さない） | `SOURCES.md` |
| `katana.glb` | 日本刀 | `SOURCES.md` |
| `rifle.glb` | ライフル（3面ボスが装備。実名は出さない） | `SOURCES.md` |
| `grenade.glb` | 未使用（取得済み資産としてのみ保持。実行時参照なし） | `SOURCES.md` |

再配布不可ライセンスのものは含めず、CC0 か帰属表記可のものを使う。出典は docs/asset-credits.md にも追記。
