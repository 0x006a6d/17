# Weapon Model Sources

All four models were downloaded from Poly Pizza, where each model page states the
license as CC0 1.0 (Public Domain). CC0 waives the creator's copyright, so attribution is
not a condition of use; creators are credited below as courtesy. CC0 covers copyright only
— it makes no statement about patent, trademark, publicity or privacy rights, which would
need to be checked separately if a model ever depicted a real product or mark.

pistol.glb, katana.glb and rifle.glb are used by the game (rifle.glb by the stage 3 gun
boss). grenade.glb is retained as an unused source asset and has no runtime reference.
