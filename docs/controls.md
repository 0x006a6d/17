# 操作方法

## 1. 入力マップ

キーボードは物理キー配列で登録してある。

|アクション|キーボード|パッド（PS 表記）|用途|
|---|---|---|---|
|`move_left` / `move_right`|A / D|左スティック 左右・十字 左右|X（進行方向）|
|`move_forward` / `move_back`|W / S|左スティック 上下・十字 上下|Z（奥 / 手前）|
|`attack`|J|□|素手コンボのパンチ入力|
|`kick`|K|×|素手コンボのキック入力|
|`fire`|U|R2|武器を使う（銃を撃つ／刀で斬る）|
|`reload`|R|L2|銃のリロード|
|`switch_weapon`|Tab|L1|武器の持ち替え|
|`dodge`|Space|R1|回避（バックフリップ）|
|`special`|O|△|必殺（回転飛び蹴り）|
|`interact`|E（長押し）|○（長押し）|踊って回復|
|`ui_accept`|Enter / テンキー Enter / Space|○ / Options|タイトル開始・カード送り・コンティニュー・結果画面を閉じる|
|（カードのスキップ）|Esc|△|カードの残りページを飛ばす。入力マップではなくキー直読み|

同じキーが2つの用途を持つ箇所が3か所ある。いずれも使う場面が排他なので競合しない。

- Space は `dodge` と `ui_accept` の両方。カード表示中・タイトル・結果画面ではツリーが止まっているか
  プレイヤーが居ないため、回避は動かない
- ○ は `interact`（踊り）と `ui_accept` の両方。同上
- △ は `special` とカードのスキップの両方。同上

マウス左クリックはタイトル・テキストカードでのみ決定として受ける（戦闘中の操作は無い）。

## 2. 移動

- 左右で X、上下で Z（奥行き）。奥行き方向は横の 0.7 倍で遅い
- 移動速度 4.5 m/s。加速 10 m/s²、減速 14 m/s²
- 向きは ±X の2方向だけ。Z 入力では向きを変えない
- 奥行きは 3 m 幅（-1.5〜1.5 m）で止まる。1〜5面とも同じ
- 画面端は、カメラに映る範囲の 0.6 m 内側で止まる
- 攻撃は互いの奥行きの差が 0.6 m 以内でないと当たらない（自分の攻撃も敵の攻撃も同じ）

## 3. 素手コンボ

`attack`（以下 P）と `kick`（以下 K）の押し順で分岐する。技は6種類で、コンボツリーの全ルートは次の6本。

|入力|技の並び|
|---|---|
|`P P P`|左ジャブ → 右ストレート → 左フック|
|`K K K`|右膝 → 右ミドル → 右ハイ|
|`P P K P K`|左ジャブ → 右ストレート → 右膝 → 左フック → 右ハイ|
|`P K P P`|左ジャブ → 右膝 → 左ジャブ → 右ストレート|
|`P K K P`|左ジャブ → 右膝 → 右ミドル → 左フック|
|`K P P P K P K`|右膝 → 左フック → 右ストレート → 左ジャブ → 右膝 → 左フック → 右ハイ|

- コンボツリーに無い入力を押した段でコンボは終わり、待機へ戻る。押さなければその段で終わる
- 途中で終わった場合、最後に当てた相手を押し離す（強さ 7.0）
- 受付は各技のクリップ再生割合で閉じる（ジャブ 85% / ストレート 90% / フック 95% / 膝 85% / ミドル 90% / ハイ 95%）。窓内の押下は先行入力として1つずつ積む
- 4物理フレーム（約 66ms）未満の連続押下は二重入力として捨てる
- 段が終わってからも 0.40 秒だけは、待機に戻っていても続きを繋げられる

技ごとの値。

|技|ダメージ|ノックバック|踏み込み初速|
|---|---:|---:|---:|
|左ジャブ|1000|1.2|1.5 m/s|
|右ストレート|2000|2.0|2.5 m/s|
|左フック（締め）|2600|10.0|3.5 m/s|
|右膝|1400|1.2|3.0 m/s|
|右ミドル|2000|2.0|2.0 m/s|
|右ハイ（締め）|3000|12.0|2.0 m/s|

締めの2技（フック・ハイ）だけが吹き飛ばす。途中段で飛ばすと次段が届かなくなるため。
命中音は技で分かれる（パンチ／キック／締め）。

## 4. 武器

`switch_weapon`（Tab / L1）を押すたびに 素手 → 日本刀 → 銃 → 素手 と巡回する。開始時は素手。
持ち替えても銃の残弾は保持する。武器を使うのは `fire`（U / R2）で、素手のときは何も起きない。
`attack` / `kick` の素手コンボは武器を持っていても変わらず出る。

### 4.1 日本刀

`fire` の連打で3段まで繋がる。

|段|ダメージ|ノックバック|リーチ（本体原点から前方端）|所要|
|---|---:|---:|---:|---:|
|初段|4000|6.0|1.40 m|0.50 秒|
|二段|5000|7.5|1.65 m|0.60 秒|
|三段（締め）|7000|10.0|1.90 m|0.75 秒|

- 次段の受付は初段 85%・二段 90% で閉じる。三段目は締めなので受け付けない
- 素手と同じ4物理フレームのデバウンス。コンボ終了後 0.1 秒は武器入力を受けない
- 判定は素手とは別枠で、段ごとに広さと位置が変わる

### 4.2 銃

|項目|値|
|---|---|
|ダメージ|4500|
|射程|22 m（正面 ±X へ水平のヒットスキャン）|
|連射間隔|0.28 秒|
|装弾数|30 発|
|リロード|`reload`（R / L2）で 1.3 秒。撃ち切らなくても押せる|

- 残弾0で `fire` を押すと撃たず、HUD の残弾欄が赤く点滅する
- 構えている間は静止し、撃った瞬間だけ発砲のモーションを重ねる。歩きながら撃つと約1秒だけ脚も発砲クリップになる
- 銃口は武器モデルの先端に追従する。射線は水平固定で、狙う操作は無い

### 4.3 一撃即死

刀と銃は当たるたびに確率で相手を即死させる。刀 15%、銃 10%。銃のそれはヘッドショットの扱いだが、当たりどころを狙う操作は無く、確率で表している。
ボスには効かず、4面では起きない。

## 5. 回避

`dodge`（Space / R1）で、向いている方向の逆へバックフリップする。

|項目|値|
|---|---|
|後退距離|2.85 m|
|所要時間|0.800 秒|
|無敵|0.800 秒（跳んでいる間の全体。着地後の無防備な余韻は無い）|
|再使用待ち|回避の 0.800 秒＋クールダウン 0.45 秒|

回避中は移動・攻撃入力を受け付けない。ダウン中・被弾ロック中は出せない。

## 6. 必殺

`special`（O / △）で回転飛び蹴り。走り込んでから全方位へ吹き飛ばす。

|項目|値|
|---|---|
|ダメージ|5500|
|ノックバック|10.0|
|判定|自分を中心とする半径 2.6 m と、正面へ距離 2.8 m・全幅 1.4 m の矩形の OR|
|前進|3.84 m/s で 3.5 m|
|着弾|入力から 0.914 秒（クールダウン 1.632 秒 × 0.56）|
|消費|自分の HP を 1500|
|再使用待ち|1.632 秒|

現在 HP が消費量以下のときは出せない。ダウン中・回避中・他の全身技の再生中も出せない。

## 7. 回復

`interact`（E / ○）を押している間だけ、毎秒 1000 の HP を回復する（プレイヤーの最大 HP は 30000）。

- 停止していないと始まらない。移動入力・攻撃入力・被弾・ダウンで中断する
- 敵の 5面ボスは、プレイヤーが踊っているとクールダウンを待たずに詰めてくる

## 8. 得点

配点は次のとおり。

|加点|値|
|---|---:|
|素手が当たる|100 × コンボの段数|
|日本刀が当たる|60 × 段数|
|銃が当たる|30（段は無いので常に1倍）|
|敵を倒す|200|
|死亡（残機を1つ失う）|−500（0 未満にはしない）|

段を掛けるので、繋げるほど1発の価値が上がる。素手7段なら 100×(1+…+7)=2800 で、単発7回の 700 の4倍。

## 9. 画面まわりの操作

|場面|操作|
|---|---|
|タイトル|`ui_accept`（Enter / Space / ○ / Options）または左クリックで1面へ|
|テキストカード|`ui_accept` で送る（文字送りの途中なら全文表示、出し終わっていれば次のページ、最後なら閉じる）。Esc / △ で残りを飛ばす|
|結果画面|`ui_accept` でタイトルへ戻る。「X に投稿」ボタンにフォーカスがあるときは投稿が優先される|

## 10. HUD の表示

|位置|内容|
|---|---|
|左上|HP（数値＋バー）、残機（無限に設定している間は「残機 ×無限」）、現在の武器、銃の残弾|
|上中央|面の題名（3.5 秒）。ボス戦に入るとボスの名前と HP バーへ替わる|
|右上|得点|
|右端|波を片付けると「GO →」が 2 秒点滅する|

## 11. ボス戦攻略

3面：ヒント：画面端
4面：ニケの身体を正面に抱えて盾にする。正面からの攻撃は通らず、側面・背後に回ると当たる。
